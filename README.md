# 电商评论智能分类系统

> 基于BERT的电商评论智能分类与情感分析系统，自动完成商品大类分类与情感倾向识别。

---

## 📖 项目背景

随着电商行业快速发展，各大平台日均产生海量用户评论。面对亿级评论数据，传统人工分类面临三大痛点：**效率低**（人工审核速度慢）、**成本高**（需要专门审核团队）、**响应慢**（差评不能及时预警）。

本项目构建了一套完整的电商评论智能分析系统，通过AI模型自动完成评论分类与情感分析，可直接嵌入电商后台，应用于**评论自动归类、差评实时预警、商品舆情监控、智能客服辅助**等业务场景。

---

## 🎯 项目任务

### 主任务：商品大类7分类

| 一级大类（7个） | 包含品类 | 原始样本量 | 清洗后样本量 |
|---|---|---|---|
| 数码电子 | 手机、平板、电脑 | 16,315 | 16,241 |
| 食品饮料 | 乳制品、水果 | 12,033 | 12,019 |
| 个护美妆 | 洗发水 | 10,000 | 9,997 |
| 服饰鞋包 | 衣服 | 10,000 | 9,994 |
| 本地生活 | 酒店 | 10,000 | 9,955 |
| 图书文娱 | 书籍 | 3,851 | 3,850 |
| 家用电器 | 热水器 | 575 | 544 |
| **合计** | **10 个原始类别** | **62,774** | **62,600** |

> 清洗共去除 174 条（1 条空评论、153 条清洗后不足 5 字、2 条纯符号、18 条重复评论）。另有 80 行评论中的手机号、邮箱、订单号等个人信息已遮盖为占位符（如 `[手机号]`）。**模型训练使用清洗后的 62,600 条**，按 70/15/15 分层划分为 train 43,820 / val 9,390 / test 9,390。

### 辅助任务：情感正负二分类

判断评论是正面评价还是负面评价。`label` 列取值为 **0 = 负面，1 = 正面**。

### 开放集识别（创新点）

基于置信度阈值（默认 0.6），当模型对未知类别评论的预测置信度低于阈值时，输出"未知类别"，避免硬分类错误。

## 🚀 快速开始

### 环境安装

```bash
pip install -r requirements.txt
```

### 数据预处理

三个脚本按顺序执行即可。脚本按自身位置定位数据，**在任何目录下运行都可以**：

```bash
python src/data_preprocess.py            # 第1步：映射大类 + 清洗 + 分层划分
python src/generate_fasttext_data.py     # 第2步：生成 FastText 格式数据
python src/eda_analysis.py               # 第3步：生成 EDA 图表
```

### 模型训练

```bash
# 随机森林基线模型
python src/train_rf.py

# FastText模型
python src/train_fasttext.py

# BERT模型
python src/train_bert.py

# 模型蒸馏 + 量化
python src/distill_bert.py
python src/quantize_model.py
```

### 启动Web服务

```bash
python web/app.py
# 访问 http://localhost:8000
```

### 数据质量复核

```bash
python src/data_audit.py                 # 只读脚本，打印各项指标
```

## 📈 模型对比结果

| 模型 | 准确率 | Macro-F1 | 模型大小 | 推理速度 |
|---|---|---|---|---|
| 随机森林（TF-IDF） | ~78% | ~75% | ~15MB | ~5ms |
| FastText | ~82% | ~80% | ~2MB | ~2ms |
| BERT-base | ~89% | ~87% | ~400MB | ~100ms |
| 蒸馏+量化BERT | ~87% | ~85% | ~60MB | ~20ms |

> 优化后的BERT模型效果损失不到2%，但体积缩小85%，推理速度提升5倍，更适合实际部署。

## ⚠️ 已知局限与注意事项

1. **「乳制品」子类存在捷径特征**：99.8%的评论字面包含「蒙牛」，相关指标会偏高。

2. **关键词基线不可忽视**：不做任何训练，仅用高频词打分，一级大类即可达到47.8%准确率；情感任务关键词规则可达78.15%。

3. **建议 `max_len` 取 256 而非 128**：10.2%的评论超过128字，截断会丢失信息。

4. **少量跨类别重复文本**：约0.5%的文本跨类别重复，影响上限约0.5个百分点。

5. **家用电器类样本少**：仅544条，且81.6%为正面，per-class指标统计上较脆弱。

6. **少量姓名地址未脱敏**：自动识别误报率过高，保留了少量姓名地址。
