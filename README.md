# 电商评论智能分类系统

## 📖 项目简介

基于BERT的电商评论智能分类系统，通过分析用户评论内容，自动判断评论所属的商品大类，并预测情感倾向。

## 🎯 项目任务

### 主任务：商品大类7分类

| 一级大类（7个） | 包含品类 | 样本量 |
|---|---|---|
| 数码电子 | 手机、平板、电脑 | 16,315 |
| 食品饮料 | 乳制品、水果 | 12,033 |
| 个护美妆 | 洗发水 | 10,000 |
| 服饰鞋包 | 衣服 | 10,000 |
| 本地生活 | 酒店 | 10,000 |
| 图书文娱 | 书籍 | 3,851 |
| 家用电器 | 热水器 | 575 |

### 辅助任务：情感正负二分类
判断评论是正面评价还是负面评价

## 🛠️ 技术栈

- **编程语言**：Python 3.9+
- **深度学习框架**：PyTorch
- **预训练模型**：BERT-base-chinese
- **传统机器学习**：Scikit-learn（随机森林）
- **快速文本分类**：FastText
- **Web部署**：FastAPI + HTML
- **版本管理**：Git + Gitee
